                       EFFICIENCYHUB QUICK START
===================================================================

WHAT TO CLICK TO OPEN THE SOFTWARE:
-------------------------------------------------------------------
👉 Double-click: EfficiencyHub.exe
   (Or double-click: 1-CLICK-START-HERE.bat)

That's it! EfficiencyHub will automatically:
1. Start the background process monitoring daemon silently.
2. Start the local optimization server.
3. Open your browser directly to http://127.0.0.1:5252 in 100% working mode.


⚠️ IMPORTANT — IF YOU DOWNLOADED A .ZIP FILE:
-------------------------------------------------------------------
Do NOT run this directly from inside 7-Zip, WinRAR, or Windows Zip preview!
You must EXTRACT the zip first:
  1. Click "Extract" at the top of 7-Zip (or right-click the zip file -> "Extract All").
  2. Open the extracted folder.
  3. Double-click "EfficiencyHub.exe" or "1-CLICK-START-HERE.bat".


REQUIREMENTS:
-------------------------------------------------------------------
- Windows 10 or 11 (64-bit)
- Microsoft .NET Framework 4.5+ (built-in on modern Windows)
- Node.js (v18+) for hosting the local dashboard (download from https://nodejs.org)
